# Design Analysis - Consumer Platform

## Visual Style

### Color Palette
- **Background**: Black (#000000) - primary background
- **Cards/Overlays**: Dark gray (#1A1A1A - #2A2A2A) - secondary surfaces
- **Text**: White (#FFFFFF) - primary text
- **Secondary Text**: Light gray (#CCCCCC - #E5E5E5) - instructions, labels
- **Text in Cards**: Dark gray/black text on light gray cards
- **Borders**: Subtle gray borders

### Layout Patterns

1. **Video/Image Dominant**
   - Large video player at top with overlay controls
   - 15-second rewind/fast-forward buttons
   - Play/pause controls
   - Fullscreen option (top right)

2. **Instruction Cards**
   - Light gray rectangular cards
   - Dark gray/black text inside
   - Stacked vertically
   - Clean, minimal styling

3. **Dark Navigation Bar**
   - Bottom navigation: dark gray/black background
   - White/gray icons
   - Multiple tabs: menu, search, star/active, mic, menu

4. **Action Buttons**
   - Bottom action bar: "Repeat", "Get Help", "Mark Complete"
   - Light gray buttons with icons
   - Prominent "Get Help" button

5. **Help Interface**
   - Dark overlay/modal
   - "Ask for help..." input field
   - FAQ section with questions
   - Clean, minimal design

6. **Safety Warnings**
   - Light gray boxes with warning icons
   - White text (SAFETY GOGGLES)

## Key UX Patterns

- **Dark mode throughout**
- **Image/video at top** - dominant visual
- **Instructions below** - in cards
- **Action buttons at bottom** - always accessible
- **Minimal chrome** - focus on content
- **Clean typography** - white on dark
- **Subtle borders** - not heavy

## B2B Adaptations Needed

1. **Employee Guide View**: Match dark mode aesthetic
2. **Step Cards**: Use light gray cards with dark text
3. **Navigation**: Dark bottom bar
4. **Action Buttons**: Match button style
5. **Background**: Black, not white
